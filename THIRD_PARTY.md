The WMA, Opus, Musepack, orthography and Unicode entries are data tables, not routines. Other fixed codewords and
transform/quantizer constants follow the formats' specifications.

The Linux sound clients (`src/linux/pw_native.cpp`, `src/linux/pulse_native.cpp`, `src/linux/spa_pod.cpp`)
are cordinal's own code speaking PipeWire's and PulseAudio's wire protocols. Their message and type
numbers and the layouts of the memory they share with the server are interface facts, checked against
the PipeWire 1.4.2 and PulseAudio 17.0 headers; no PipeWire, libspa or PulseAudio code is used or linked.

Windows supplies WASAPI, Direct2D, DirectWrite, WinHTTP, SChannel, the UCRT and other system
components; Windows builds use its image loader instead of stb_image, and SChannel instead of BearSSL.

The Windows release is packed by cdpack (`cdpack/`), cordinal's own packer, decoder and loader. It
contains no UPX code; it is GPL-2.0-or-later (`cdpack/COPYING`), and `cdpack/PROVENANCE.md` records
its sources. Building it needs LLVM-MinGW's clang and Python 3.14, which release CI downloads at
pinned versions; neither is part of the player. `build.bat stock-nrv` packs with
[UPX](https://upx.github.io/) 5.2.1 instead, downloaded and hash-checked by `tools/pack-release.ps1`,
with its unmodified stub.

New dependencies must have GPL-3.0-or-later-compatible licenses and be recorded here and in
`src/third_party/README.md`.
